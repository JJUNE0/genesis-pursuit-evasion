## Goal

τ-aware forecaster의 **τ misspecification** 영향 측정. (τ_actual, τ_input) ∈ {10, 25, 50}² 9-cell grid + τ-unaware adjacent column. Paper Figure 7.

Headline: **"τ-aware degrades under misspec; τ-unaware is misspec-immune by design"**.

## Method

`scripts/eval_misspec_grid.py` — sweeps:

| dim | values | n |
|---|---|---|
| pairs | a5_d6, a7_d8, a8_d9, a9_d10 | 4 |
| τ_actual (env's true delay) | 10, 25, 50 | 3 |
| τ_input (forecaster declared) | 10, 25, 50 (τ-aware grid) + N/A (τ-unaware) | 3 + 1 |
| seeds | 42 (single — E1 multi-seed가 forecaster intrinsic 측정) | 1 |
| **total cells (τ-aware)** | 4 × 3 × 3 = 36 | |
| **total cells (τ-unaware)** | 4 × 3 = 12 | |
| **grand total** | | **48** |

### Per-cell setup
- `num_episodes`: 500
- `num_envs`: 64
- `num_euler_steps`: 10
- env 항상 `tau_delay = tau_max=50`, defender_state_history에서 τ_actual 위치 lookup
- τ-aware: forecaster.forward(τ=τ_input) 호출
- τ-unaware: τ_input 개념 없음 (model에 τ 안 줌) — adjacent column

## Devil's Advocate

### 짚어야 할 약점
1. **τ-aware는 τ_train과 모든 τ_input에서 학습됨** (Pattern 2 random τ): training data에서 (τ_input != τ_actual)는 본 적 없을 수도. 단 τ_input ∈ [1, 50] uniform 학습이라 model은 일반화 가능. 실제 결과로 확인.
2. **Misspec 시나리오의 현실성**: 사용자가 "τ를 잘못 measure"하는 상황. 실제 packet timing measurement는 noisy → ±10 step 정도 mismatch는 흔함. 본 grid는 ±40 step extreme — paper에서 "worst case bound" framing.
3. **τ-unaware single-seed**: misspec eval은 forecaster intrinsic이 아니라 deployment effect라 single seed OK. E1에서 multi-seed coverage.

### Reviewer 예상 공격 + 답
- **"실제 misspec 분포는 ±10 step 정도지 ±40은 unrealistic"** → "We report the full grid for thoroughness; intermediate cells (e.g., τ_actual=25, τ_input=10) approximate realistic ±15 step error. The point is: τ-unaware avoids any misspec scenario."
