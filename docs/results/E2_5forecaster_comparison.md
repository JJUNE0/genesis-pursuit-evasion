5-way forecaster comparison on 4 attacker-defender pairs at τ ∈ {10, 25, 50}.

## Method

`scripts/eval_5forecasters.py` — sweeps:

| dim | values | n |
|---|---|---|
| pairs | a5_d6, a7_d8, a8_d9, a9_d10 | 4 |
| τ | 10, 25, 50 | 3 |
| forecaster | no_fc / naive_constvel / tau_aware_flow / tau_unaware_flow / tau_unaware_det | 5 |
| seed | 42, 0, 1 | 3 |
| **total cells** | | **180** |

### Per-cell setup
- `num_episodes`: 500
- `num_envs`: 64
- `num_euler_steps`: 10 (Flow inference)
- env tau_delay = τ (for the cell), env-injected PretrainedDefender, external PretrainedAttacker
- attacker obs's defender slot stub-replaced by forecaster output (flow returns last-step prediction)

### Forecasters used
| | ckpt path |
|---|---|
| τ-aware Flow | `logs/forecaster/ams_v9_multi_v1/best.pt` |
| τ-unaware Flow | `logs/forecaster/tau_unaware_v1/best.pt` (seed 42 — main) |
| τ-unaware Det | `logs/forecaster/tau_unaware_det_v1/best.pt` |
| Naive const-vel | math only, no ckpt |
| No FC | env raw obs, no model |

### Multi-seed strategy
Per master plan (Q2): headline cells (τ=50 × 4 pair × 5 fc) get 3 seeds (42/0/1).
Lower-τ cells get single seed (compute budget). For τ-unaware Flow, all 3 seeds use
matching forecaster ckpts (`tau_unaware_v1`, `tau_unaware_v1_seed0`, `tau_unaware_v1_seed1`).

## Devil's Advocate

### 짚어야 할 약점 (paper limitation)
1. **Plug-in evaluation** — attacker는 perfect-info에서 학습. forecaster output을 처음부터 보고 학습한 게 아님 (joint training은 future work). 따라서 결과는 "forecaster의 deploy-time benefit lower bound" — joint training 시 더 좋아질 가능성.
2. **Pair variance** (a5_d6, a7_d8 잘 됨 / a8_d9, a9_d10 약함 패턴 가능) — Figure 5에서 정직 reporting. defender strength gating finding으로 framing.
3. **Multi-seed for forecaster training** — flow forecaster는 3 seed 학습 (42/0/1). naive/no_fc는 deterministic. τ-aware reference는 단일 seed (ams_v9_multi_v1).
4. **τ-aware의 사용된 τ_input은 cell의 τ_actual과 일치** — 즉 best-case로 평가. E4 (misspec grid)에서 mismatch 영향 별도 측정.

### Reviewer 예상 공격 + 답
- **"왜 from-scratch joint training 안 했나?"** → "Plug-in benefit alone shows method value; joint training extension is principled and left as future work given compute budget."
- **"a8_d9 등 일부 pair에서 benefit 없음"** → "Defender strength gating: forecaster benefit appears when defender reactively challenges attacker enough to make delay penalty observable. We report all pairs (Figure 5) for transparency."
